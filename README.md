# Expense Tracker

A Spring Boot based Expense Tracker application for managing and tracking daily expenses with MySQL database integration.

## Features

- Add and manage expenses
- View expense records
- RESTful API using Spring Boot
- MySQL database integration
- JPA/Hibernate for database operations
- Simple web interface

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- Maven
- Git & GitHub
